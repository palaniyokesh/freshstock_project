FreshStock Inventory Dashboard — Empty Starter Version

Files in this folder:
- index.html: website structure
- styles.css: visual design
- script.js: stock, expiry, and reorder interactions

How to run:
1. Keep all three files in the same folder.
2. Double-click index.html to open it in Chrome or Edge.
3. Use Stock & Expiry Manager to enter products manually.
4. Enter opening stock, weekly sales estimate, unit cost, supplier lead time, pack size, batch ID, expiry date, and received date.
5. Click Add product / batch. Use the table buttons to receive stock, record sold/removed units, or mark a batch expired.
6. Use Export stock & expiry CSV to back up your inventory.

The product list starts empty. Inventory is saved in this browser only using localStorage; it is not a shared multi-user real-time database. Sales/forecast chart is clearly illustrative and is not connected to POS sales data.
